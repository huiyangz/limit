# ST002 检查账户机构是否可匹配到限额场景配置

## 步骤描述

1.获取账户开立行行号：根据{账号}查询【账户信息】获取$账户开立行行号$
2.获取限额场景编码：根据[账户开立行行号]查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$

3.判断是否继续匹配上级机构：若[限额场景编码]为空，则跳转至子步骤《获取上级机构集合》，否则返回[限额场景编码]

4.获取上级机构集合：根据[账户开立行行号]查询【机构信息表】获取[上级机构集合]

5.检查上级机构匹配的限额场景：按照[上级机构集合]中的$机构层级$从大到小遍历[上级机构集合]：
1.根据[上级机构集合]的$机构号$查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$。

2.若[限额场景编码]为空，则继续遍历下一条，否则中断本次遍历并返回[限额场景编码]。
3.结束遍历并返回[限额场景编码]为空。

> 2.获取限额场景编码：根据[账户开立行行号]查询【限额控制配置表】获取$启用标志$等于"Y-启用"的$限额场景编码$

同一机构多条启用记录时的取值规则未定义。工程事实：IRbLimitCtrlConfBcc 主键为「限额机构编码+限额场景编码」，同一机构允许配置多条限额场景，findByEo 按机构+启用标志查询返回 List。本子步骤及子步骤5.1（第10行）仅"获取$限额场景编码$"，命中多条启用（validFlag=Y）记录时取哪条、是否返回集合未定义。多条启用属主键设计允许的常态，取值规则直接决定返回结果，无法唯一实现。需确认：多条启用记录时的取值规则（按何条件或排序取一条、返回集合由调用方处理、还是视为配置异常），子步骤5.1 同样适用。
