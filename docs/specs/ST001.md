# ST001 获取限额场景编码

## 步骤描述

1.获取允许自定义标识：根据[限额场景编码]查询【限额控制配置表】获取$允许自定义标识$，若【限额控制配置表】无记录，则返回[限额场景编码]为空
2.获取限额信息：若[允许自定义标识]为"N-否",则返回[限额场景编码]，否则跳转至子步骤《获取自定义限额》

3.获取自定义限额：查询【限额控制客户自定义配置表】获取$限额场景编码$等于[限额场景编码]、$客户号$等于{客户号}且$生效日期$小于等于{交易日期}的自定义限额，多条记录时取$生效日期$最大的一条

4.获取限额值：检查[自定义限额]，获取对应限额信息:
1.若[自定义限额]存在且$临时限额标志$等于"Y-是"且{交易日期}大于$失效日期$，则返回[限额场景编码]为空。若[自定义限额]存在且$临时限额标志$等于"Y-是"且{交易日期}小于等于$失效日期$，则返回[限额场景编码]。

2.若[自定义限额]存在且$临时限额标志$等于"N-否"，则返回[限额场景编码]。
3.若[自定义限额]不存在且限额控制配置表中$仅检查客户自定义标志$等于"Y-是"，则返回[限额场景编码]为空。
4.若[自定义限额]不存在且限额控制配置表中$仅检查客户自定义标志$等于"N-否"，则返回[限额场景编码]。

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |
| clientNo | java.lang.String | 必填 | | 客户号 |
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |
| tranDate | java.util.Date | 必填 | | 交易日期 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
