# ST007 匹配限额场景

## 步骤描述

1.获取规则关系表达式：根据业务场景中的因子（即【限额规则关系表】主键 ruleId，黑名单检查规则编号，结果唯一）查询【限额规则关系表】获取配置好的$规则关系表达式$，查无记录时直接返回检查结果为“未匹配到限额场景”

2.获取限额场景编码列表：根据[关系规则表达式]查询【限额规则关系表（RB_LIMIT_RULE_RELATION）】获取其对应的[限额场景编码列表]，包括$限额场景编码$

3.检查是否匹配到限额场景：遍历[限额场景编码列表]：
1.根据$限额场景编码$查询【限额场景定义表】获取$启用标志$等于"Y"的[配置数据]（Y 表示启用）；

2.若[配置数据]不为空，则中断本次遍历，并返回检查结果为“已匹配到限额场景”；
3.遍历结束（含[限额场景编码列表]为空）且均未命中启用配置时，返回检查结果为“未匹配到限额场景”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| factorName | java.lang.String | 必填 | | 因子名称 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 非必填 | 限额规则关系（RB_LIMIT_RULE_RELATION） | 限额场景编码（匹配到的限额场景编码） |
| ruleRelationExpr | java.lang.String | 非必填 | 限额规则关系（RB_LIMIT_RULE_RELATION） | 关系规则表达式 |
| validFlag | java.lang.String | 非必填 | 限额场景定义（RB_LIMIT_SCENE_DEF） | 启用标志 |
| checkResult | java.lang.String | 非必填 | | 检查结果：已匹配到限额场景 / 未匹配到限额场景 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
