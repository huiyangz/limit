# ST008 登记累计限额

## 步骤描述

1.登记累计限额：若[限额检查结果]为“未超限”，且[限额累计金额]等于0或者[限额累计笔数]等于0，则登记限额信息，$限额场景编码$等于[限额场景编码]，$限额检查对象值$根据{限额场景码}在限额场景定义表（RB_LIMIT_SCENE_DEF）中配置的$限额检查对象类型$赋值为{账号}或者{客户号}（检查对象类型为账户级别 ACCT 时取{账号}，为客户级别 CUST 时取{客户号}，本步骤不支持其他检查对象类型），$限额累计金额$等于{交易金额}，$限额累计笔数$等于1，$生效日期$等于{系统日期}，$失效日期$等于{系统日期}加[限额场景编码]配置的$周期类型$$周期值$，其他字段的取值按照系统规则自动生成。
