# ST009 检查限额场景配置是否有效

## 步骤描述

1.获取限额场景控制区间：根据[限额机构编码]、[限额场景编码]查询【限额控制配置】获取$限额控制开始日期$、$限额控制结束日期$、$限额控制开始时间$、$限额控制结束时间$；未查询到配置记录时按检查不通过处理，[限额场景编码]返回为空。

2.检查交易时间：若{交易日期}在[限额控制开始日期]至[限额控制结束日期]范围内，且{交易时间}在[限额控制开始时间]至[限额控制结束时间]范围内，则返回[限额场景编码]及$限额控制开始日期$、$限额控制结束日期$、$限额控制开始时间$、$限额控制结束时间$，否则[限额场景编码]与上述四个控制区间字段全部返回为空。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranDate | java.util.Date | 必填 | | 交易日期 |
| tranTimestamp | java.lang.String | 必填 | | 交易时间（格式HHmmss），即步骤描述中的{交易时间} |
| limitBranchId | java.lang.String | 必填 | | 限额机构编码 |
| limitSceneNo | java.lang.String | 必填 | | 限额场景编码 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额场景编码 |
| limitCtrlBgnDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始日期 |
| limitCtrlEndDate | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束日期 |
| limitCtrlBgnTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制开始时间 |
| limitCtrlEndTime | java.util.Date | 非必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额控制结束时间 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
