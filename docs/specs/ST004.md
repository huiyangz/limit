# ST004 检查限额

## 步骤描述

1.获取限额控制值：根据[限额机构编码]和[限额场景编码]查询【限额控制配置】获取对应的$限额控制金额$和$限额控制笔数$

2.检查限额：若[限额累计金额]大于[限额控制金额]或[限额累计笔数]大于[限额控制笔数]，则返回限额检查结果为“超限”，否则返回限额检查结果为“未超限”。

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |

| limitSumAmt | java.math.BigDecimal | 必填 | | 限额累计金额 |
| limitSumNum | java.lang.Integer | 必填 | | 限额累计笔数 |
| limitBranchId | java.lang.String | 必填 | | 限额机构编码 |
