# ST003 计算限额累计金额

## 步骤描述

1.计算限额累计金额：根据[限额场景编码]以及{限额检查对象值}优先在【限额控制客户自定义配置表】中获取[限额信息]，未获取到再在【限额控制配置表】中获取[限额信息]，$累计类型代码$取自【限额控制配置表】中该场景的配置，获取后计算[限额累计金额]及[限额累计笔数]：

1、若[限额信息]的$限额控制类型$等于"O-单笔金额"，无需计算$累计限额$；
2、若[限额信息]的$限额控制类型$等于“N-累计笔数、A-累计金额、B-累计笔数/金额”且当$累计类型代码$等于"1-自然周期"或者“3-指定日期范围”或者“4-指定时间范围”或者“5-指定日期+时间范围”，则根据[限额场景编码]以及{限额检查对象值}在【限额累计信息表】中查询对应的[累计限额信息]

3、检查[累计限额信息]的累计限额值是否在生效范围内即系统日期大于等于生效日期且小于失效日期，若是存在,则返回[限额累计金额]等于$限额累计金额$加{交易金额}，[限额累计笔数]等于$限额累计笔数$加1；若是不存在,则返回[限额累计金额]等于{交易金额}，[限额累计笔数]等于1

4、若[限额信息]的$限额控制类型$等于“N-累计笔数、A-累计金额、B-累计笔数/金额”且当$累计类型代码$等于"2-滑动窗口"，则根据[限额场景编码]以及{限额检查对象值}、{客户号}以及【限额控制配置表】中$周期值$和$期限类型$在【滑动流水表】中查询[有效周期内的限额]

5、若[有效周期内的限额]存在，则返回[限额累计金额]等于按【限额场景定义表】中$限额折算方式$确定的金额之和（原币种汇总$交易金额$、折算汇总$限额折算金额$），[限额累计笔数]等于所有交易笔数之和，若不存在,则返回[限额累计笔数]等于1，[限额累计金额]等于{交易金额}

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSceneNo | java.lang.String | 必填 | 限额控制配置（RB_LIMIT_CTRL_CONF） | 限额场景编码 |
| tranAmt | java.math.BigDecimal | 必填 | | 交易金额 |
| checkObjVal | java.lang.String | 必填 | | 限额检查对象值 |
| clientNo | java.lang.String | 必填 | | 客户号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| limitSumAmt | java.math.BigDecimal | 非必填 | | 限额累计金额 |
| 否 | java.lang.Integer | 非必填 | | 限额累计笔数 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
